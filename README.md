# Octavian Portfolio

Modern **3D developer portfolio** for Octavian Popovici / EAGLE VISION.

## Stack

- Next.js (App Router)
- React Three Fiber + Drei (hero 3D)
- Framer Motion (3D tilt cards, reveals)
- Tailwind CSS v4

## Dev

```bash
npm install
npm run dev
```

## Deploy

Connected to Vercel via GitHub.
